# Interface sound credits

The four cues in this folder are **original synthesized audio**, generated by
`scripts/generate-ui-sounds.mjs` using plain sine waves and noise. No
third-party samples, melodies or recordings are included.

| File | Use | Author | Licence |
| --- | --- | --- | --- |
| `click.wav` | button, link and control clicks | AgroRotate team | CC0 1.0 Universal (public domain dedication) |
| `type.wav` | text entry | AgroRotate team | CC0 1.0 Universal |
| `whoosh.wav` | route change and preview transition | AgroRotate team | CC0 1.0 Universal |
| `resolve.wav` | form submit and cycle reset | AgroRotate team | CC0 1.0 Universal |

You may copy, modify and redistribute these files without attribution. The
attribution above is provided because the interface credits its sources.

Regenerate with:

```bash
node scripts/generate-ui-sounds.mjs
```
